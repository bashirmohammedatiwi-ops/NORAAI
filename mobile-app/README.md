# NURAI Drive Mobile (Flutter) v3

تطبيق سائق متكامل — مجموعة تطبيقات داخل تطبيق واحد.

## التطبيقات الداخلية

| التطبيق | الوصف |
|---------|--------|
| **الرئيسية** | لوحة تحكم + اختصارات لكل التطبيقات |
| **الخرائط** | خريطة حية، أحداث قريبة، سرعة، أقرب خطر |
| **الكاميرا** | كاميرا كاملة الشاشة + اكتشاف AI ومربعات |
| **الموديل** | اسم الموديل، الإصدار، الكلاسات، مزامنة |
| **التنبيهات** | تنبيهات مباشرة + أحداث قريبة |
| **قيادة كاملة** | خريطة + كاميرا + لوحة معاً |

## التشغيل

```bash
cd mobile-app
flutter pub get
flutter run
```

السيرفر الافتراضي: `http://187.127.88.146:8080`
