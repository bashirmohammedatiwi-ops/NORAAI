# تصدير تقرير راصد

## الهوية
- **اسم المشروع:** راصد (RASID)
- **المسابقة:** NURAI
- **الطلاب:** بشير محمد · سلمان داود · مهدي احمد
- **الإشراف:** د. مهند عبدالاله
- **الجامعة:** جامعة تكنولوجيا المعلومات والاتصالات

## الملف

**`Rasid-Report-Print.html`** — 13 صfحة A4 مرتبة

## تصدير PDF (زر حقيقي)

1. افتح `Rasid-Report-Print.html` في **Google Chrome**
2. انتظر تحميل المخططات (~3 ثوانٍ)
3. اضغط **تصدير PDF** — يُحمَّل `Rasid-Report-NURAI.pdf`
4. كل صfحة HTML = صfحة PDF واحدة (13 صfحة)

> يُفضَّل Chrome + اتصال إنترنت (للخطوط والمكتبات).

## Word

Word → Open → `Rasid-Report-Print.html` → Save as .docx
